# DevBrother Claude Plugins

Claude Code plugins by DevBrother.

## Installation

```
/plugin marketplace add devbrother2024/claude-plugins
```

## Available Plugins

### cross-verify

AI cross-verification skill that compares answers from Codex (GPT), Gemini, and Claude.

```
/plugin install cross-verify@devbrother-plugins
```

See [cross-verify README](./plugins/cross-verify/README.md) for details.
